# Play-by-Play-AI-Game-Commentary

<img width="183" alt="image" src="https://github.com/rafaykek/Play-by-Play-AI-Game-Commentary/assets/128332969/2be1003f-5b9f-4ea6-9812-ecafe3c6cff6">

Play-by-Play AI is a product for online games that enhances the gaming experience by providing real-time generated commentary. This commentary will be dynamic and context-specific, avoiding the repetitive nature of preset commentaries that many games currently use.
